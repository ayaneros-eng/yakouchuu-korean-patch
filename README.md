# 야광충 한글패치

슈퍼패미컴(SNES) 게임 야광충(夜光虫 / Yakouchuu)의 비공식 한글패치입니다.
개인이 보유한 일본 원판에 적용하는 BPS 패치이며, 게임 ROM은 포함하지 않습니다.

현재 버전: **2026-10-01 검수본** (Stage 18.31 기반).

## 다운로드

- [배포 버전 및 ZIP 다운로드](https://github.com/ayaneros-eng/yakouchuu-korean-patch/releases)
- [한글패치 BPS 다운로드](./Yakouchuu_KO_Release_QA_20261001.bps)
- [배포 파일 SHA-256](./SHA256SUMS.txt)

위 BPS 링크에서 GitHub의 파일 다운로드 버튼을 눌러 저장하세요.

## 패치에 필요한 원본 ROM

| 항목 | 적용 대상 |
| --- | --- |
| 게임 | 야광충 / 夜光虫 / Yakouchuu |
| 기종 | 슈퍼패미컴(Super Famicom / SNES) |
| 판본 | 일본 원판 (Japan), 일본어판 |
| 파일 형식 | 헤더 없는 ROM (`.sfc` 또는 `.smc`) |
| 정확한 크기 | 2,097,152바이트 (2 MiB) |
| CRC32 | `0CD0E8D8` |
| SHA-1 | `000e0846e4b5514138d435ebbe50b23294fdd921` |
| SHA-256 | `8a368c313103c5c6381b9cb2cd221aad90c7247caf7745316360051f71fc4fa8` |

같은 게임 이름이나 확장자만으로는 적용 대상을 확인할 수 없습니다. 크기와 해시가 일치하는 원본을 사용하세요.
다른 기종 판본, 기존 한글패치 ROM, 수정된 ROM은 이 패치의 적용 대상이 아닙니다.
원본 ROM과 패치 적용 후 ROM은 이 저장소나 배포 ZIP에 포함하지 않습니다.

## 패치 적용 방법

1. 헤더 없는 일본 원판 ROM을 준비합니다. 정확한 파일 크기는 **2,097,152바이트**입니다.
2. BPS 지원 패치 도구를 실행합니다. 웹 도구인 [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)도 사용할 수 있습니다.
3. `ROM file`에 일본 원판을, `Patch file`에 `Yakouchuu_KO_Release_QA_20261001.bps`를 지정하고 `Apply patch`를 누릅니다.
4. 생성된 ROM을 SNES 에뮬레이터에서 실행합니다. 정상 결과는 **4,194,304바이트**이며, 아래 SHA-256과 일치합니다.

이 패치는 일본 원판에 한 번 적용합니다. 기존 한글패치 ROM에 덧씌우지 마세요.
512바이트 복사기 헤더가 붙은 원본이나 다른 버전은 적용 대상이 아닙니다.
원본 ROM의 제공·다운로드 안내는 하지 않습니다.

### 적용 대상과 결과 해시

| 파일 | SHA-256 |
| --- | --- |
| 일본 원판 (2,097,152바이트) | `8a368c313103c5c6381b9cb2cd221aad90c7247caf7745316360051f71fc4fa8` |
| 패치 적용 결과 (4,194,304바이트) | `67cfc06c5ccedd807d03cc5800bcac52f4f55c054b611801c21633943247f313` |
| BPS 패치 | `90ae75cf9dc495e30d40c26b7fbafd378b1c7e8bbaf5b45f6c00e337397f787f` |

Windows PowerShell에서 `Get-FileHash -Algorithm SHA256 -LiteralPath '게임파일.sfc'`로 확인할 수 있습니다.

## 조작 및 저장

- 본문 페이지 넘김: **L**
- 선택지 이동: **R**(다음), **L**(이전)
- 선택 확정: **A**

다른 패치 버전에서 만든 세이브스테이트는 재사용하지 마세요.
이 검수본의 배터리 저장 후 재부팅·불러오기는 6개 구간에서 확인했습니다.

## 이번 검수본의 수정 사항

- 본문을 읽은 뒤 선택지를 새 페이지에 모아 마지막 선택지가 누락되는 문제를 수정했습니다.
- 후반부의 긴 선택지 설명을 줄여 세 항목이 같은 페이지에 표시되도록 했습니다.
- 저장 복귀와 화면 재표시 중 선택 입력 처리를 보강했습니다.
- 오역과 용어 불일치 5곳을 교정했습니다.
- 타이틀과 종료 화면의 한자는 유지했습니다.

## 검수 범위와 확인된 한계

Snes9x libretro 코어에서 곤도·살인벌·밀항자 세 계열을 대상으로 **종료까지 총 23회** 진행했습니다.
검수 경로에서는 추가 텍스트 잘림·페이지 초과·크래시가 발견되지 않았습니다.
원판과 비교한 22개 완료 경로는 종료 저장 데이터가 일치했습니다.

23회는 서로 다른 23개 엔딩이나 모든 플래그 조합을 검증했다는 뜻은 아닙니다.
보석 엔딩은 목표 경로가 다른 경로로 합류해 해당 엔딩을 확인하지 못했습니다.
전체 엔딩 후 보너스의 일부 교정 문장은 개별 출력으로 확인했으며, 자연 해금 전체는 검증하지 않았습니다.
다른 에뮬레이터 코어·실기와 전체 번역의 의미·문체에 대한 전수 검수도 완료하지 않았습니다.

## 문제 제보

텍스트 잘림, 미번역, 오역 또는 크래시를 발견하면 이 저장소의 Issues에 알려주세요.
버전, 에뮬레이터 이름·버전, 발생 위치, 직전에 고른 선택지, 재현 방법을 함께 적으면 확인에 도움이 됩니다.
가능하면 문제가 보이는 화면을 첨부하고, 게임 ROM은 첨부하지 마세요.

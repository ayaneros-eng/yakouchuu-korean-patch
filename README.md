# 야광충 한글패치

슈퍼패미컴(SNES) 게임 야광충(夜光虫 / Yakouchuu)의 비공식 한글패치입니다.
개인이 보유한 일본 원판에 적용하는 BPS 패치이며, 게임 ROM은 포함하지 않습니다.

현재 버전: **v2026.10.01.1 — 선택지 표시 수정본** (Stage 18.31 기반).

## 다운로드

- [최신 수정본 ZIP 다운로드](https://github.com/ayaneros-eng/yakouchuu-korean-patch/releases/latest)
- [이전 버전 및 배포 이력](https://github.com/ayaneros-eng/yakouchuu-korean-patch/releases)
- [한글패치 BPS 다운로드](./Yakouchuu_KO_ChoiceFix_20261001.bps)
- [배포 파일 SHA-256](./SHA256SUMS.txt)

위 BPS 링크에서 GitHub의 파일 다운로드 버튼을 눌러 저장하세요.

## 패치에 필요한 원본 ROM

| 항목 | 적용 대상 |
| --- | --- |
| 게임 | 야광충 / 夜光虫 / Yakouchuu |
| 기종 | 슈퍼패미컴(Super Famicom / SNES) |
| 판본 | 일본 원판 (Japan), 일본어판 |
| 파일 형식 | 헤더 없는 ROM (`.sfc` 또는 `.smc`) |
| 정확한 크기 | 2,097,152바이트 (2 MiB) |
| CRC32 | `0CD0E8D8` |
| SHA-1 | `000e0846e4b5514138d435ebbe50b23294fdd921` |
| SHA-256 | `8a368c313103c5c6381b9cb2cd221aad90c7247caf7745316360051f71fc4fa8` |

같은 게임 이름이나 확장자만으로는 적용 대상을 확인할 수 없습니다. 크기와 해시가 일치하는 원본을 사용하세요.
다른 기종 판본, 기존 한글패치 ROM, 수정된 ROM은 이 패치의 적용 대상이 아닙니다.
원본 ROM과 패치 적용 후 ROM은 이 저장소나 배포 ZIP에 포함하지 않습니다.

## 패치 적용 방법

1. 헤더 없는 일본 원판 ROM을 준비합니다. 정확한 파일 크기는 **2,097,152바이트**입니다.
2. BPS 지원 패치 도구를 실행합니다. 웹 도구인 [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)도 사용할 수 있습니다.
3. `ROM file`에 일본 원판을, `Patch file`에 `Yakouchuu_KO_ChoiceFix_20261001.bps`를 지정하고 `Apply patch`를 누릅니다.
4. 생성된 ROM을 SNES 에뮬레이터에서 실행합니다. 정상 결과는 **4,194,304바이트**이며, 아래 SHA-256과 일치합니다.

이 패치는 일본 원판에 한 번 적용합니다. 기존 한글패치 ROM에 덧씌우지 마세요.
512바이트 복사기 헤더가 붙은 원본이나 다른 버전은 적용 대상이 아닙니다.
원본 ROM의 제공·다운로드 안내는 하지 않습니다.

### 적용 대상과 결과 해시

| 파일 | SHA-256 |
| --- | --- |
| 일본 원판 (2,097,152바이트) | `8a368c313103c5c6381b9cb2cd221aad90c7247caf7745316360051f71fc4fa8` |
| 패치 적용 결과 (4,194,304바이트) | `8c03324d9f99db322c0e26ec37cd7669aebf9886c186d259563f0e6a3cd45391` |
| BPS 패치 | `70be51fc90138536c9ec5b95e59aa09c938b529237215f30df3235e629e073a5` |

Windows PowerShell에서 `Get-FileHash -Algorithm SHA256 -LiteralPath '게임파일.sfc'`로 확인할 수 있습니다.

## 조작 및 저장

- 본문 페이지 넘김: **L**
- 선택지 이동: **R**(다음), **L**(이전)
- 선택 확정: **A**

다른 패치 버전에서 만든 세이브스테이트는 재사용하지 마세요.
이번 수정본의 배터리 저장 후 재부팅·불러오기는 긴 선택지와 4개 항목 선택지를 포함해 7개 구간에서 확인했습니다.
업데이트할 때 일본 원판에 새 BPS를 적용하고, 이전 버전의 세이브스테이트 대신 게임 내 저장을 이용하세요.

## 이번 수정본의 수정 사항

- 선택지 페이지를 지우는 작업이 끝나기 전에 글자를 그려 첫 번째 항목의 첫 글자가 사라지는 문제를 수정했습니다.
- 저장 후 이어하기에서 선택 강조 띠가 글줄보다 아래에 표시되는 문제를 수정했습니다.
- 제보된 의무실 장면에서 본문과 첫 번째 선택지가 섞이지 않고, 세 항목이 별도 페이지에 정상 표시되는 것을 확인했습니다.

### 이전 2026-10-01 검수본에 포함된 수정

- 본문을 읽은 뒤 선택지를 새 페이지에 모아 마지막 선택지가 누락되는 문제를 수정했습니다.
- 후반부의 긴 선택지 설명을 줄여 세 항목이 같은 페이지에 표시되도록 했습니다.
- 저장 복귀와 화면 재표시 중 선택 입력 처리를 보강했습니다.
- 오역과 용어 불일치 5곳을 교정했습니다.
- 타이틀과 종료 화면의 한자는 유지했습니다.

## 검수 범위와 확인된 한계

이번에는 선택지 표시와 조작을 중심으로 추가 검수했습니다. 페이지 지우기 수정 단계에서 Snes9x로 새 게임과 이어하기의 **120개 선택 위치(중복 포함 142개 화면), 353번 선택 조작**을 확인했습니다. 선택지의 글자 누락·화면 초과를 실제 캡처와 대조하고, 이동·확정 후 다음 선택지 또는 종료까지의 진행을 점검했습니다.

최종 배포 파일에서는 Snes9x와 bsnes로 **초반 13개 선택지, 코어별 28개 선택 화면**의 글자 표시를 대조했습니다. 별도로 저장 데이터만으로 재부팅한 7개 구간에서 글자, 강조 띠 정렬, 선택 확정 후 진행을 재검증했습니다. 이 추가 검수 중 진행 불가나 크래시는 발견되지 않았습니다.

이전 2026-10-01 검수본에서는 Snes9x libretro 코어로 곤도·살인벌·밀항자 세 계열을 **종료까지 총 23회** 진행했고, 원판과 비교한 22개 완료 경로의 종료 저장 데이터가 일치했습니다. 이후 제보와 추가 검수에서 첫 글자 누락과 강조 띠 어긋남이 확인되어 이번 버전에 반영했습니다.

23회는 서로 다른 23개 엔딩이나 모든 플래그 조합을 검증했다는 뜻은 아닙니다.
보석 엔딩은 목표 경로가 다른 경로로 합류해 해당 엔딩을 확인하지 못했습니다.
전체 엔딩 후 보너스의 일부 교정 문장은 개별 출력으로 확인했으며, 자연 해금 전체는 검증하지 않았습니다.
bsnes 검수는 초반 선택지 구간에 한정됩니다. 실기, 모든 에뮬레이터, 모든 플래그 조합과 전체 번역의 의미·문체에 대한 전수 검수는 완료하지 않았습니다.

## 오류 제보 / 검수 피드백

텍스트 잘림, 미번역, 오역 또는 크래시를 발견하면 이 저장소의 Issues에 알려주세요.
버전, 에뮬레이터 이름·버전, 발생 위치, 직전에 고른 선택지, 재현 방법을 함께 적으면 확인에 도움이 됩니다.
가능하면 문제가 보이는 화면을 첨부하고, 게임 ROM은 첨부하지 마세요.

[Issues 목록](https://github.com/ayaneros-eng/yakouchuu-korean-patch/issues)에서 같은 문제가 이미 등록되어 있는지 간단히 검색한 뒤,
[한글패치 오류 제보](https://github.com/ayaneros-eng/yakouchuu-korean-patch/issues/new?template=01-error-report.yml) 양식을 작성해 주세요.
패치 설치 질문, 의견, 건의는 [기타 문의](https://github.com/ayaneros-eng/yakouchuu-korean-patch/issues/new?template=02-question.yml) 양식을 이용해 주세요.
제보 등록에는 GitHub 로그인이 필요합니다.

- 가능하면 문제 하나당 Issue 하나로 작성하고, 서로 다른 오류는 나눠서 제보해 주세요.
- 오역, 일본어 원문 잔존, 오탈자, 글자 잘림·깨짐, 그래픽 문제, 선택지 문제, 진행 불가 등을 제보할 수 있습니다.
- 사용 중인 한글패치 버전을 적어 주세요. 텍스트 잘림·글자 깨짐·번역 오류는 스크린샷 첨부를 강하게 권장합니다.
- Issue 작성 칸을 클릭한 뒤 이미지를 드래그하거나 붙여넣으면 스크린샷을 첨부할 수 있습니다.
- 원본 게임 데이터나 ROM·ISO·NSP·XCI 파일은 첨부하지 말아 주세요.

### 관리 방법

관리자는 [Issues 목록](https://github.com/ayaneros-eng/yakouchuu-korean-patch/issues)에서 제보 제목을 눌러 내용을 확인하고 댓글로 답변하면 됩니다.
오류 제보에는 `bug`, 기타 문의에는 `question` 라벨이 자동으로 붙습니다.
필요하면 Issue 오른쪽의 Labels에서 `translation`(번역), `typo`(오탈자), `font`(글자 깨짐),
`ui`(표시), `japanese-left`(일본어 잔존), `gameplay`(진행), `patch`(적용) 중 해당 라벨을 추가하세요.
문제 종류 선택에 따른 세부 라벨은 관리자가 붙입니다.

수정한 버전을 배포했으면 댓글에 버전을 적고 `fixed` 라벨을 붙인 뒤 **Close issue**를 누르면 됩니다.
해결된 제보는 Closed 목록에서 다시 볼 수 있습니다.
